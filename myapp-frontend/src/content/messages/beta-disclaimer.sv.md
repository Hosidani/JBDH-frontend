# Välkommen till JBDH Beta

JBDH är för närvarande i **beta** och utvecklas aktivt. Det innebär att:

- Funktionalitet kan vara ofullständig eller förändras utan förvarning
- Fel och brister kan förekomma
- Vi reserverar oss för driftstörningar och avbrott

Vi arbetar kontinuerligt med att förbättra tjänsten och uppskattar din förståelse.

# Användning av AI

JBDH använder artificiell intelligens (AI) för att analysera CV:n, matcha kandidater mot jobb och ge rekommendationer. Det är viktigt att känna till att:

- **AI kan ha fel.** Alla analyser, matchningar och rekommendationer ska betraktas som ett stöd — inte som absoluta sanningar.
- **Granska alltid resultaten** innan du fattar beslut baserade på dem.
- **AI-modeller kan vara partiska** och återspegla mönster från träningsdata som inte alltid är representativa.

Använd JBDH som ett verktyg bland andra, inte som ensam beslutsgrund.
